# Paso 1 — Investigación de referencias

Objetivo: salir con **patrones concretos y justificados**, no con "inspiración". Una referencia sirve si se puede
señalar exactamente qué se toma de ella (retícula, paleta, tratamiento tipográfico, un elemento firma).

## Dónde buscar (mínimo 3 tipos de fuente)

| Tipo | Fuente | Qué aporta |
|---|---|---|
| Galerías de BI | Power BI Data Stories Gallery (community.fabric.microsoft.com) | Lo que es posible en Power BI real: fondos, navegación, tarjetas |
| | Tableau Public · Viz of the Day (public.tableau.com) | Composición editorial, portadas de dashboards, uso del color |
| | Plantillas de Power BI de consultoras (búsqueda "Power BI report design template") | Retículas y menús laterales reutilizables |
| Periodismo de datos / editorial | The Pudding, Financial Times (Visual Vocabulary), NYT Upshot, Reuters Graphics | Jerarquía, titulares que dicen el hallazgo, color con intención |
| | Information is Beautiful Awards (informationisbeautifulawards.com) | Piezas premiadas: conceptos fuertes |
| | Storytelling with Data (blog), Datawrapper (blog) | Reglas de claridad y color "gris + 1 acento" |
| Diseño de producto / UI | Dribbble y Behance (buscar "dashboard", "analytics", "annual report cover", "retail dashboard") | Tendencias visuales, portadas, tarjetas KPI |
| | Muzli, Mobbin | Patrones de UI reales |
| Color | Adobe Color (Explore/Trends), Coolors, ColorBrewer, paleta Okabe-Ito | Armonías y paletas accesibles |
| Dominio | Informes anuales y webs de cadenas de retail, empaques, señalética de supermercado | Metáforas y lenguaje visual del sector |

Cuidado con Dribbble/Behance: muchas piezas son conceptos sin datos reales (tarjetas decorativas, gráficos
inventados, contraste bajo). Tomar de ahí **estética**, no reglas de visualización.

## Consultas sugeridas (ajustar al dominio)

- `"Power BI" report cover page design` · `Power BI landing page navigation design`
- `retail sales dashboard design dribbble` · `supermarket analytics dashboard UI`
- `annual report cover design data` · `editorial data visualization layout grid`
- `Tableau viz of the day retail` · `dashboard color palette accessible`

Para **ver** las imágenes: usar la búsqueda de imágenes o abrir la página en el navegador y tomar captura.
Nunca describir una referencia que no se ha visto. Guardar el enlace de cada una.

Mínimo 8 filas. Después:

**Adoptamos** (3–5): p. ej. "dato héroe enorme en la portada", "gris para todo y un solo acento", "tiras de
color por categoría tomadas de la señalética de góndola".

**Evitamos** (3): p. ej. "gradientes neón", "tarjetas con sombra fuerte", "íconos clip-art".

## Extraer el patrón, no copiar la pieza

Para cada referencia, describir en abstracto: proporción de zonas (p. ej. 40/60), tamaño relativo del dato
principal frente al texto (p. ej. 6:1), número de colores y su función, alineación (izquierda / centrada),
cantidad de espacio en blanco, elemento firma. Luego recombinar en un diseño propio. No usar logos, marcas,
fotos ni ilustraciones de terceros en el entregable.
